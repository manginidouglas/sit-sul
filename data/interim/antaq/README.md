# Camada ANTAQ — Onda 1

`instalacoes_elegiveis_2025.csv` é uma camada **conservadora e comprovada**, não um censo completo: contém os portos organizados cuja movimentação anual aparece nominalmente no Anuário ANTAQ 2025 (p. 19) e cujas coordenadas constam da camada geográfica oficial de 06/05/2025. O bulk detalhado do Estatístico Aquaviário permaneceu inacessível; por isso não é possível classificar exaustivamente os TUPs. Ausência nesta camada não significa inelegibilidade.
