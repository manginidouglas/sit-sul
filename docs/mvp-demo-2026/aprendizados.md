# O que aprendemos executando o MVP

* **Dados/fontes:** recurso público não implica esquema estável; período exige evidência congelada.
* **Metodologia:** configuração experimental protege fichas normativas.
* **Geoespacial:** elegibilidade oficial e caminho navegável são problemas distintos; mercado nacional amplia muito a matriz de rotas.
* **Software:** fórmulas puras mantêm testes sem rede; publicação bloqueia universo errado, duplicidade, domínio e degeneração.
* **Comunicação:** ranking sem cobertura, componentes e disclaimer é enganoso.
* **Versão completa:** automatizar manifestos, OSRM, IPF, relatório estatístico e dashboard após o portão.

Uma execução honesta pode terminar com pendências explícitas; preencher lacunas para “completar” o produto viola a rastreabilidade.
